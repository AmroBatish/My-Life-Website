# Elbatish World 🌍

This is a **personal website project created for learning purposes**.  
The website was built entirely from scratch using **HTML and CSS**, without relying on any external libraries or frameworks.

The goal of this project was to practice building a complete website structure and improve my **front-end development skills**.

The website is also **fully responsive**, providing a smooth experience across different screen sizes such as desktops, tablets, and mobile devices.

---

## 📖 Project Overview

**Elbatish World** is a **demo personal website concept** used as a practice project.  
It simulates a personal platform where someone might share different aspects of their interests and activities.

The website includes example sections such as:

- 📚 Books someone might be reading
- 🎮 Games someone might be playing
- ✨ Stories, events, and personal updates

These sections are **sample content used for practicing layout, structure, and design**, and do not represent real personal content.

---

## 🚀 Key Features

- **Responsive Design**  
  The layout adapts smoothly to different devices including **desktop, tablet, and mobile**.

- **Learning Project**  
  Created as part of my journey to practice **front-end web development**.

- **Built from Scratch**  
  Developed using only **vanilla HTML and CSS**, with no external libraries or frameworks.

- **Clean and Minimal Design**  
  A simple and modern layout focused on readability and easy navigation.
