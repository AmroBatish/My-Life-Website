# Elbatish World - Personal Website

This is a **personal website** that I created entirely from scratch using **HTML** and **CSS**, with no external libraries or frameworks. The website is **fully responsive**, providing a smooth user experience across different screen sizes.

## Project Overview:

"**Elbatish World**" is a creative personal space where I share everything about my life, including:

- **Books I am reading**
- **Games I am playing**
- **Stories and Events**

The purpose of this project is to provide an interactive platform for reflecting my interests and ideas.

## Key Features:

- **Responsive Design**: The website adapts seamlessly to any device (desktop, tablet, or mobile), ensuring a smooth experience for all users.
- **Personalized Content**: Sections dedicated to articles, galleries, and updates about my personal life.
- **Built from Scratch**: Developed using only **vanilla HTML** and **CSS**, with no reliance on external libraries or frameworks.
- **Minimalistic and Modern Design**: A clean, simple layout with a focus on user experience and easy navigation.
